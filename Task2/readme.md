# Star Wars Wiki Scraper

Скрипт для скачивания страниц с Star Wars Fandom Wiki и извлечения текста описания.

## Установка зависимостей

### Способ 1: Использование pip 
```bash
# Создание виртуального окружения
python -m venv .venv

# Активация виртуального окружения
# На Windows:
\.venv\Scripts\activate.bat
# На macOS/Linux:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
